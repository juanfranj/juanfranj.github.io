Step-by-step guide Guia paso a paso

1

Create an account Crea una cuenta

Visit platform.openai.com and click "Sign up". You can use email, Google, Microsoft, or Apple. Visita platform.openai.com y haz clic en "Sign up". Puedes usar email, Google, Microsoft o Apple.

2

Verify your email Verifica tu email

Check your inbox and click the verification link sent by OpenAI. Revisa tu bandeja de entrada y haz clic en el enlace de verificacion enviado por OpenAI.

3

Verify your phone number Verifica tu numero de telefono

OpenAI requires SMS verification. Enter your phone number and the code you receive via text message. OpenAI requiere verificacion por SMS. Introduce tu numero de telefono y el codigo que recibas por mensaje de texto.

4

Set up billing Configura la facturacion

Go to Settings → Billing → Add payment method. You need to add credits (minimum ~$5) to use the API. Ve a Settings → Billing → Add payment method. Necesitas agregar creditos (minimo ~$5) para usar la API.

💡 You can skip this initially, but the API won't work without credits loaded into your account. Puedes omitir esto inicialmente, pero la API no funcionara sin creditos cargados en tu cuenta.
5

Navigate to API Keys Navega a API Keys

In the left sidebar, click "API Keys" or go directly to platform.openai.com/api-keys En la barra lateral izquierda, haz clic en "API Keys" o ve directamente a platform.openai.com/api-keys

6

Create a new secret key Crea una nueva clave secreta

Click "Create new secret key". Give it a descriptive name like "CheesCoach". Haz clic en "Create new secret key". Dale un nombre descriptivo como "CheesCoach".

7

Copy your key immediately! Copia tu clave inmediatamente!

Your API key (starts with sk-...) is displayed. Copy it right away. Tu API key (comienza con sk-...) se muestra en pantalla. Copiala de inmediato.

⚠️ IMPORTANT: The key is only shown ONCE. If you close the dialog without copying it, you'll need to create a new one. There is no way to view it again. IMPORTANTE: La clave solo se muestra UNA VEZ. Si cierras el dialogo sin copiarla, tendras que crear una nueva. No hay forma de verla de nuevo.
8

Paste in CheesCoach Pega la clave en CheesCoach

Open CheesCoach → Settings → AI section → Select "OpenAI GPT-4o-mini" → Configure → Paste your API key Abre CheesCoach → Ajustes → Seccion IA → Selecciona "OpenAI GPT-4o-mini" → Configurar → Pega tu API key

✅ Your key is stored securely on your device using AES-256-GCM encryption. It is never sent to our servers. Tu clave se almacena de forma segura en tu dispositivo usando cifrado AES-256-GCM. Nunca se envia a nuestros servidores.
