Creating your API Key Crear tu API Key

1

Create an account Crear una cuenta

Visit platform.deepseek.com and click "Sign Up". Visita platform.deepseek.com y haz clic en "Sign Up".

2

Verify your email Verificar tu email

Check your inbox and click the verification link. Revisa tu bandeja de entrada y haz clic en el enlace de verificacion.

3

Phone verification (optional) Verificacion telefonica (opcional)

Phone verification is optional but recommended. Supports international numbers from 180+ countries. La verificacion telefonica es opcional pero recomendada. Admite numeros internacionales de mas de 180 paises.

4

Navigate to API Keys Ir a API Keys

In the left sidebar, click "API Keys". En la barra lateral izquierda, haz clic en "API Keys".

5

Create API Key Crear API Key

Click "Create API Key" and give it a descriptive name (e.g. "CheesCoach"). Haz clic en "Create API Key" y ponle un nombre descriptivo (ej. "CheesCoach").

6

Copy your key Copiar tu clave

Copy the key immediately — it won't be shown again after closing the window. Copia la clave inmediatamente — no se mostrara de nuevo despues de cerrar la ventana.

7

Paste in CheesCoach Pegar en CheesCoach

Open CheesCoach → Settings → AI section → Select "DeepSeek Chat" → Configure → Paste your API key. Abre CheesCoach → Ajustes → Seccion IA → Selecciona "DeepSeek Chat" → Configurar → Pega tu API key.

Adding Funds (for international users) Agregar Fondos (para usuarios internacionales)

⚠️
Payment may be challenging El pago puede ser complicado

DeepSeek is a Chinese company and payment can be challenging for users outside China. Below are your options, from easiest to most involved. DeepSeek es una empresa china y el pago puede ser complicado para usuarios fuera de China. A continuacion tus opciones, de la mas facil a la mas compleja.

A
Use your free tokens first Usa tus tokens gratis primero
Recommended Recomendado

New accounts get 5 million free tokens. This is enough for many analysis sessions. Try it before worrying about payment. Las cuentas nuevas reciben 5 millones de tokens gratis. Esto es suficiente para muchas sesiones de analisis. Pruebalo antes de preocuparte por el pago.

B
PayPal

If PayPal is available in your country:

  1. Go to platform.deepseek.com/top_up
  2. Select "PayPal"
  3. Follow the PayPal payment flow
  4. Minimum top-up: ~$2

Si PayPal esta disponible en tu pais:

  1. Ve a platform.deepseek.com/top_up
  2. Selecciona "PayPal"
  3. Sigue el flujo de pago de PayPal
  4. Recarga minima: ~$2
Note: PayPal is NOT available in all countries. If you see an error, try the other options. Nota: PayPal NO esta disponible en todos los paises. Si ves un error, prueba las otras opciones.
C
Bank Card Tarjeta Bancaria
  1. Go to Top Up → Select "Bank Card"
  2. Enter your Visa/Mastercard details
  3. Some international cards may be rejected depending on your region
  1. Ve a Top Up → Selecciona "Bank Card"
  2. Introduce los datos de tu Visa/Mastercard
  3. Algunas tarjetas internacionales pueden ser rechazadas dependiendo de tu region
D
Virtual Card with Crypto Tarjeta Virtual con Cripto

If PayPal and bank cards don't work, you can use a crypto-funded virtual card:

  1. Create an account on a service like Kazawallet (kazawallet.com) — requires identity verification (KYC)
  2. Deposit cryptocurrency (USDT recommended for stability)
  3. Convert to USD and issue a virtual Visa card
  4. Use the virtual card details in DeepSeek's "Bank Card" payment option

Si PayPal y las tarjetas bancarias no funcionan, puedes usar una tarjeta virtual financiada con cripto:

  1. Crea una cuenta en un servicio como Kazawallet (kazawallet.com) — requiere verificacion de identidad (KYC)
  2. Deposita criptomonedas (USDT recomendado por estabilidad)
  3. Convierte a USD y emite una tarjeta Visa virtual
  4. Usa los datos de la tarjeta virtual en la opcion "Bank Card" de DeepSeek
Note: fees apply (~4% total). Nota: se aplican comisiones (~4% en total).
E
Use OpenRouter as intermediary Usar OpenRouter como intermediario
Recommended alternative Alternativa recomendada

If you can't pay DeepSeek directly, OpenRouter.ai acts as a middleman:

  1. Create an account at openrouter.ai
  2. Buy credits with a normal credit card (they use Stripe — works worldwide)
  3. In CheesCoach settings, use the OpenRouter API key instead

Si no puedes pagar a DeepSeek directamente, OpenRouter.ai actua como intermediario:

  1. Crea una cuenta en openrouter.ai
  2. Compra creditos con una tarjeta de credito normal (usan Stripe — funciona en todo el mundo)
  3. En los ajustes de CheesCoach, usa la API key de OpenRouter en su lugar

CheesCoach's DeepSeek provider uses the same API format as OpenRouter, making this a seamless alternative. El proveedor DeepSeek de CheesCoach usa el mismo formato de API que OpenRouter, lo que hace que sea una alternativa transparente.
