Setup Guide

AI Coach Configuration

Connect CheesCoach to an AI provider to unlock intelligent chess coaching. Choose one provider and follow its setup guide.

What are API keys?

An API key is a unique password that lets CheesCoach connect to an AI service to analyze your chess games. Think of it like a library card — it identifies you so the AI provider knows who is making the request.

You only need to set up ONE provider. Choose whichever suits you best. Your key is stored encrypted on your device and never shared.

💡 New to AI APIs? We recommend starting with Google Gemini — very low cost (pennies per month) and easy to set up.
